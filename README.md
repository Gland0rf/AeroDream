
# AeroDream

**A Frutiger Aero-inspired shader pack for Minecraft Java Edition.**


## Features

- Crystal-blue water with waves, reflections, and underwater effects
- Vibrant greenery with animated foliage
- Dreamy skies, moving clouds, and atmospheric lighting
- Rainbows, rain ripples, and glossy wet surfaces
- Beautiful glass, ice, and snow effects
- Pastel sunsets, blue-hour lighting, and optional auroras

## Visual Styles

- **Classic Aero** — Fresh greens, bright skies, and the iconic 2000s look
- **Tropical Aero** — Turquoise water and vibrant tropical colors
- **Soft Dream** — Gentle pastel colors and dreamy lighting

## Installation

1. Install [Iris Shaders](https://www.irisshaders.dev/).
2. Download the latest AeroDream ZIP.
3. Place it in your `.minecraft/shaderpacks` folder.
4. Enable AeroDream in Minecraft's shader settings.

## Performance

Choose between three quality presets:

- **Performance** — Lightweight effects for better FPS
- **Balanced** — A balance between visuals and performance
- **Dream** — Maximum visual quality
